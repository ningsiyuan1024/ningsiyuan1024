# Sylan

我在做面向知识工作者的 Agent Harness，关注 Agent 如何长程执行、从反馈中改进，以及如何在关键步骤让人看得见、接得住。此前在来也科技参与桌面办公 Agent、AI Coding 工作流和 Computer Use 预研。现在也在参与相关开源项目。

## 代表项目

| 项目 | 我在做什么 |
| --- | --- |

## 研究兴趣

- **Agent 运行时**：持续运行（always-on）、主动协作（proactive）、长程任务与多 Agent 协作。
- **Harness 自进化**：用轨迹、反馈和评测迭代 Skills 与执行流程。
- **上下文与记忆**：组织工具、任务状态与长期记忆，让 Agent 在合适的时候拿到可用信息。

## 关于我

我在山东大学学习物理和人工智能，后来在新加坡国立大学从计算物理转向 AI for Science。课外喜欢攀岩和摄影，也会把生活里的问题做成小产品。「天赋商业化」就是其中一个：帮助人把兴趣和才华做成自己的产品。
